# 즉석 퀴즈

주제와 난이도를 입력하면 Claude가 그 자리에서 4지선다 객관식 퀴즈 5문제를 만들어주는 학습용 웹앱입니다.

## 기능
- 주제(자유 입력) + 난이도(쉬움/보통/어려움) 선택
- Claude가 그 자리에서 문제 5개(보기 4개, 정답, 한 줄 해설)를 생성
- 문항별 즉시 정답 확인, 최종 점수 표시
- 오답노트 저장/조회/삭제
- "다시 풀기"로 같은 주제·난이도의 새 문제 재생성
- 한국어 UI, 모바일 친화적 레이아웃

## 실행 방법
이 앱은 Claude Artifact(claude.ai)의 런타임 capability(`sample`, `db`)를 사용해 별도의 API 키 없이 Claude를 호출합니다. 그래서 일반 브라우저에서 `즉석퀴즈.html`을 그냥 열면 퀴즈 생성 기능은 동작하지 않고, Claude Artifact로 게시된 상태에서만 정상 동작합니다.
