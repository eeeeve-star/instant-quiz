# 즉석 퀴즈

『현대사회와 윤리』(해냄에듀) Ⅱ단원(생명윤리와 생태윤리) 본문만 근거로 Claude가 그 자리에서 4지선다 객관식 퀴즈 5문제를 만들어주는 학습용 웹앱입니다.

**GitHub Pages 배포 링크**: https://eeeeve-star.github.io/instant-quiz/

## ⚠️ 배포 링크에서는 퀴즈 생성이 동작하지 않아요
이 앱은 별도 서버나 API 키 없이, **Claude 아티팩트(claude.ai) 자체에 내장된 기능**을 통해 Claude를 호출합니다. 그 기능은 claude.ai 안에서 열었을 때만 존재해서, GitHub Pages 링크(또는 이 HTML 파일을 다운로드해서 그냥 여는 경우)에서는 화면과 디자인만 보이고 "퀴즈 만들기"를 눌러도 문제가 생성되지 않습니다. (버튼을 누르면 "이 화면은 Claude 앱(claude.ai) 안에서 열어야 퀴즈를 만들 수 있어요"라는 안내가 뜹니다.)

실제로 문제를 풀어보려면 Claude 아티팩트 링크로 열어야 합니다.

## 기능
- 단원 선택(생명윤리와 생태윤리 3개 소단원) + 난이도(쉬움/보통/어려움) 선택
- 선택한 소단원의 교과서 본문만 근거로 Claude가 문제 5개(보기 4개, 정답, 한 줄 해설)를 생성
- 문항별 즉시 정답 확인, 최종 점수 표시
- 오답노트 저장/조회/삭제
- "다시 풀기"로 같은 단원·난이도의 새 문제 재생성
- 한국어 UI, 모바일 친화적 레이아웃

## 파일 구성
- `index.html`, `즉석퀴즈.html` — 앱 전체(HTML/CSS/JS) 단일 파일 (동일한 내용, GitHub Pages가 `index.html`을 기본으로 서빙합니다)
